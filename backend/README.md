# FarmMarket — Backend

API REST de FarmMarket (NestJS, Prisma, PostgreSQL).

L'installation, la configuration, le lancement, les tests et la liste des routes sont décrits dans le [README principal](../README.md).

Commandes courantes (depuis ce dossier) :

```bash
npm run start:dev    # lancer l'API en développement (http://localhost:3001)
npm test             # tests unitaires
npm run test:e2e     # tests e2e (base farmmarket_test)
npm run seed:admin   # créer le compte administrateur
```
